# 수정한 화면을 다시 확인합니다

[진행자 기록지 열기](https://sokldjs554.github.io/harbinger/retest.html) · [실제 계산 데모](https://sokldjs554.github.io/harbinger/live.html)

참가자는 데모를 사용하고 진행자는 기록지를 별도 탭에서 엽니다. 공개 페이지의 기록지에도 관찰 결과는 서버로 전송되지 않습니다. 별칭·버전·실행 환경·자료 조건·이전 사용 경험을 입력한 뒤, 같은 7개 과업을 순서대로 진행합니다. CSV 과업은 실제 계산 환경에서만 수행합니다.

1. 시작 버튼을 누른 뒤 과업을 설명합니다. 화면 위치나 정답을 먼저 알려주지 않습니다.
2. 서버를 기다릴 때는 ‘대기’, 설명·휴식에는 ‘중단’, 다시 조작할 때는 ‘조작 재개’를 누릅니다. 다른 탭으로 옮겨도 시계는 계속 갑니다. 컴퓨터 절전·시계 동작이 의심스러운 기록은 측정 근거로 사용하지 않습니다.
3. 도움을 줬다면 내용을 남기고 ‘도움 후 완료’를 선택합니다. 완료하지 못하면 막힌 지점을 적습니다. 하지 않은 과업은 ‘미실시’로 기록합니다.
4. 마지막에 JSON을 내려받습니다. 기록은 자동 저장되지 않으며, 현재 도구는 완료·미실시로 정리한 7과업을 한 파일로 저장합니다. 다시 시도하는 경우 새 기록으로 남기고 이전 기록도 보존합니다.
5. 공개 인용은 기록 동의와 별도로 확인합니다. 회사명·직원 이름·연락처·실제 점검 원문은 입력하지 않습니다.

대기는 진행자가 표시한 구간입니다. 실제 API 응답시간과 같다고 주장하지 않습니다. 파일 형식 검증은 사건 순서와 시간 합계·도움 여부의 모순을 검사할 뿐, 관찰자의 진술이나 파일 진위를 독립적으로 인증하지 않습니다.

## 기록을 확인하려면

```bash
python -m scripts.retest_records after.json
# 같은 참가자·환경·과업/자료 조건의 전후 기록이 실제로 있을 때만
python -m scripts.retest_records before.json --after after.json
```

이 비교는 실제 관찰 기록만 허용합니다. 자동 검사 파일은 `record_kind=tool-test`로 표시되고 사람의 비교에서 제외됩니다. 미실시·미완료 과업의 시간을 성공 과업 시간으로 비교하지 않습니다. 같은 사람의 재검토는 학습 효과와 진행 순서의 영향을 받으므로 일반 사용자 전체나 UI 변경의 인과 효과로 확대하지 않습니다.

현재 전달받은 ‘추가 문제 없음’ 회신은 그대로 보존합니다. 새 도구로 측정한 사람의 기록은 아직 받지 않았습니다. 이전 시간·발언을 소급 생성하지 않으며, 이번 도구의 자동 브라우저 시험은 사용자 재측정 완료를 뜻하지 않습니다.
