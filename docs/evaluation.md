# 평가 계약과 결과 해석

이 문서의 현재 수치는 `artifacts/*.json`에서 생성한다. 수정 전 수치는 `artifacts/archive/fd346c7/`에 보존하며 현재 결과와 혼용하지 않는다. `artifacts/before_after.json`은 같은 생성 데이터·패키지·시드로 다시 실행한 비교다. 기존 공개 수치를 그대로 수정 전 재현값이라고 부르지 않는다.

## 시간 경계

점검 시각 t 기준 학습은 t < 2025-01-01, 보정·조기종료는 그 이후 t < 2025-07-01, 테스트는 이후다. 분류는 t+30일 <= 각 구간 관측 cutoff인 행만 사용한다. 정확히 cutoff에 성숙하는 라벨은 포함한다. 생존은 해당 cutoff까지 event/tte_days를 함께 행정 중도절단하고, cutoff에 정확히 일어난 사건은 보존한다. 모델 선택·전처리·검열 분포 추정도 그 자료만 사용한다. 최종 30일 미성숙 행은 음성으로 채점하지 않는다.

고객별 에너지 전처리는 이전 달까지 자료로 적합하고 fit_until에서 고정한다. 60일 미만이면 결측 처리하며 전체 미래 자료로 대체하지 않는다. 원자료 SHA-256·전처리 버전·fit_until·관측 종료가 다르면 캐시를 재생성한다. 과거 재현의 held_out은 로드한 모델 번들의 관측 종료 메타데이터만 신뢰한다. 메타가 없으면 평가 보류다.

HGB 내부 조기종료는 성숙한 학습 자료의 무작위 일부를 사용한다. 이것은 독립 시간 검증 성능으로 보고하지 않는다. 보정 선택은 별도 검증 구간에서 교차적합하고 테스트를 사용하지 않는다. PyTorch 조기종료는 검증 경계에서 중도절단한 NLL로 선택한다. 모델 관측 종료는 보정/조기종료의 가장 늦은 cutoff다.

## 비교 대상과 목표

- 분류: HGB, 전체 특징 로지스틱, 연식/최근 판정만 학습한 제한 모델. AUROC, PR-AUC, Brier, ECE.
- 생존: Cox, AFT, PyTorch 위험 네트. C-index와 IPCW Brier. 테스트 추적 기간 밖이거나 검열 생존확률이 0.05 이하인 평가 시점은 보류한다. 서로 다른 지원 시점의 IBS를 직접 비교하지 않는다.
- 에너지: 별도 kWh 회귀의 MAE/RMSE/MAPE. 고장 분류 점수와 혼합하지 않는다.
- 순찰: 동일 날짜·사이트·K=10에서 HGB, 딥러닝, 로지스틱, 메모/이력 제거 모델, 최근 판정·연식·최근 고장·오래 미점검 규칙 및 무작위 기대치를 비교한다. 순수 위험순 평가와 중요도·기한 규칙을 포함하는 기존 처방 목록은 다른 정책이다.

30일 창은 겹치고 같은 설비가 반복된다. 주간 행을 독립 표본으로 간주하지 않는다. 전체 고객사 시계열을 묶어 재표집하는 paired site-cluster bootstrap 2,000회로 Precision@K 및 최근 판정 규칙 대비 차이의 95% 구간을 계산한다. 이는 합성 고객사 간 변동을 반영하며 현실의 분포 변화까지 보장하지 않는다. 단일 날짜 웹 분석은 신뢰구간 없이 기술통계만 제공한다.

## 기여도와 고객사 보류

메모·품질·고장 이력을 각각 제거한다. 메모 제거 시 메모 유래 품질 가중치와 가중 판정 특징도 제거한다. 품질 제거 시 품질 가중 판정 특징도 제거한다. 단순 접두사 삭제만으로 관련 정보가 남지 않도록 한다. 고객사 보류 실험은 유형별 2개, 총 8개를 선정하며 전체 25개를 모두 LOSO 평가한 것이 아니다. 해당 고객사의 학습·보정 정답을 제외하고, 에너지 전처리에서도 해당 고객사 적합을 없애기 위해 en 특징을 제외한다. 0개월/3개월/6개월/12개월 자체 정답 보정은 각각의 라벨 성숙 경계를 적용한다. 제외·미선정·양성 부족 사이트를 산출물에 기록한다.

현재 웹의 고객사별 표는 한 기준일의 결과다. 별도 LOSO 결과와 같은 것으로 표시하지 않는다. 업로드는 합성 학습 모델을 적용하는 탐색적 계산이며, 고객 고유 모델 학습이나 실제 고객 실증 완료를 뜻하지 않는다.
