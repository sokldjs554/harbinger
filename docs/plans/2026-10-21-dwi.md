# DWI 지원용 harbinger 실행 계획

기준: main fd346c75ddae39fa6383096d7dd6adabccfdb044. 새 체크아웃, 사용자 미커밋 변경 없음. AGENTS.md와 라이선스 파일 없음. 기존 저작권/라이선스를 변경하지 않는다.

## 목적과 선택
채용 담당자가 합성 예제를 실행하거나 지원 CSV를 넣어 데이터 오류 → 설비 우선순위 → 원문 근거 → 과거 결과 → 고객사별 평가/보류 → 다운로드를 확인한다. 기존 Python/FastAPI/HGB/PyTorch와 바닐라 JS를 유지한다. 별도 프레임워크 재작성은 검증 범위를 불필요하게 늘린다. 외부 LLM·유료 API는 쓰지 않는다.

1. 실패 회귀 테스트: 분류 라벨 성숙, 생존 행정 중도절단, 미래 기록 불변성, 에너지 전처리, 모델 메타 없는 replay.
2. 분할 공통 관측 cutoff를 적용한다. t+30일 <= cutoff만 분류에 사용하고 생존 event/tte를 함께 자른다. 에너지 전처리는 미래 fallback을 없앤다. 캐시는 원자료 해시/설정/버전으로 식별한다. 모델 번들에 관측 종료를 남긴다.
3. 동일 생성 시드·데이터·모델 설정으로 이전/이후 실행. 메모/품질/이력 제거, 단순 모델, 고객사 보류와 시간 보류를 함께 측정. 의존성을 보존하는 고객사 단위 bootstrap을 사용한다. 미성숙·단일 클래스는 보류한다.
4. 기존 API와 모델 계산을 재사용하는 세션 API. 업로드는 정해진 CSV 묶음을 받고 최대 크기·행·사이트·설비·날짜·참조 무결성을 검증한다. 공유 예제와 분리, TTL/개수 제한, 메모리 내 보관, 임의 pickle/실행파일 금지. 정답 관측 종료는 사용자가 명시한다.
5. 첫 화면을 안내 중심 작업 공간으로 연결한다. 서버 계산/저장 예제를 구별하고 오류·로딩·빈 결과·모바일을 검증한다. 결과 JSON/CSV 및 한국어 보고서를 제공한다.
6. pytest/실제 평가/API/Playwright/Docker 검증. 한국어 README, 동일 버전의 정적 데모·평가 JSON·보고서, 60~90초 녹화와 검증 로그. 공개 배포는 가능한 권한과 비용 범위에서 진행하며 불가능한 부분은 명시한다.

## 해석 원칙
모든 예제는 합성이다. 관측 기간/정답/모델 메타 부족은 0점이 아니라 평가 보류다. 기존 수치는 archive로 분리한다. What-if는 인과 효과가 아니다. 법정 주기는 데모 가정이다. 실제 DWI DB·직무 배정·조직 상황은 추정하지 않는다.
