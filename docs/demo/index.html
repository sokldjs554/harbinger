한 행은 inspection / breakdown / preventive / parts 중 한 기록입니다. 예제 CSV의 열 이름을 유지하세요. 설비·고객사·기록 ID, 설비 분류, 설치일, 중요도, 층, 구역, 기록 시각이 필수이며 점검 행에는 점검자·판정(0 양호/1 주의/2 불량)·체류 시간·예정일·방식·사진 수가 필요합니다. 메모는 빈 문자열을 허용합니다. 날짜는 YYYY-MM-DD 또는 시간대 없는 ISO 시각, 모든 기록은 동일한 현장 시간대, 최대 5년을 지원합니다. 중복·누락·알 수 없는 열과 형식은 자동 수정하지 않고 알려드립니다.

업로드에는 에너지 피처를 사용하지 않습니다. 합성 데이터로 학습한 모델의 탐색적 추론이며 실제 고객 성능의 증거가 아닙니다. 파일은 서버 로그나 디스크에 저장하지 않습니다.
