## Fixed conditions

Only inspection raw inputs at or after the original 24-month training cutoff are damaged. All earlier records and all labels remain unchanged. Seed is data seed + 2000. Independent conditions (not combined) are:

1. `clean`: unchanged inputs.
2. `cluster_asset`: for each (site, asset), phase = SHA256(`seed:cluster_asset:site:asset`) first 8 bytes interpreted unsigned big-endian modulo 56. Remove the memo when (integer days from training cutoff + phase) modulo 56 is below 28. Thus each group has continuous 28-day missing blocks in a fixed 56-day cycle; realized deletion depends on inspection cadence.
3. `cluster_inspector`: the identical rule grouped by (site, inspector), with its own condition salt. This correlates absence across an inspector's assets.
4. `selective_missing`: memo text alone determines severity, before corruption. High if any of `심함, 심각, 긴급, 불량, 파손, 불가, 과열, 정지, 중지, 트립, 연기, 침수` occurs; otherwise medium if any of `주의, 증가, 저하, 누유, 누수, 진동, 소음, 발열, 탄내, 불안정, 오염, 부식, 마모` occurs; otherwise low. Delete with probability .80/.50/.10 for high/medium/low, using independent row RNG seeded by SHA256(`seed:selective_missing:inspection_id`) first 8 bytes big-endian. No future labels, latent state, workorders or learned severity model enter this transform.
5. `hangul_substitution`: for each eligible memo, row RNG seeded by SHA256(`seed:hangul_substitution:inspection_id`), replace each precomposed Hangul syllable with probability .15. Preserve initial/final consonants and swap the vowel index using pairs (0,4), (1,5), (2,6), (3,7), (8,13), (9,14), (10,15), (11,16), (12,17), (18,20); index19 maps to20. Preserve all other characters. This synthetic vowel substitution is a distinct test from the previous random character deletion; it is not a measured Korean typing-error distribution.
6. `abbreviations`: deterministic replacement of every occurrence in the following ordered synthetic mapping: `특이사항 없음→특이無`, `정상 작동 확인→정상확인`, `운전 상태 양호→운전OK`, `점검 완료→점검完`, `교체 필요→교체要`, `수리 필요→수리要`, `주의 관찰→주의관찰`, `베어링→BRG`, `앵커볼트→앵커BT`, `필터→FLT`, `배터리→BATT`, `오일→OIL`, `온도→TEMP`, `압력→PRESS`, `전류→AMP`. These are plausible but explicitly invented test abbreviations, not validated customer vocabulary.
7. `delay_7d`: unchanged memo content; at each decision use only inspection records whose performed time + 7 days is at or before the decision, using the existing `decision_snapshot` contract. Workorders remain immediately available, and time-dependent features are refreshed at decision time. This is inspection delivery delay, not delay of every data source. Uniform lag preserves inspection ordering and history at the source inspection.

Rebuild every memo-derived feature from transformed raw inspections, including inspector-quality and weighted checklist features. Energy source is unchanged, so its original fitted energy features may be reused by inspection ID rather than re-fitting. Verify all nonmemo inputs and labels unchanged for memo conditions; no_memo predictions must be bitwise invariant across these conditions. Delay legitimately changes other inputs.
