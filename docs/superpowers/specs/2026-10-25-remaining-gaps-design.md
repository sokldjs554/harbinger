# 남은 약점을 검증 가능한 기능으로 연결합니다

사용자가 2026-10-25 감사에서 확인한 남은 항목 전부의 보완을 요청했다. 실제 현장 자료와 사람의 과업 재측정 결과는 생성하지 않는다. 구현 선택은 기존 Python/FastAPI/바닐라 JS를 유지하는 것으로 정했다. 공개 합성 데모를 유지하며 보호 모드는 별도 설정으로 활성화한다. 외부 유료 API, 새 유료 인프라는 사용하지 않는다.

## 범위와 판단

1. 신호표: 행 독립 Wilson 구간 대신 사이트 단위 cluster bootstrap을 적용한다. 같은 설비/점검자가 사이트 안에 반복되는 구조를 보존한다. 사이트가 부족하면 구간을 보류한다. 기존 원시 수치와 과거 보고서는 덮어쓰지 않고 새 산출물의 방법·시드·반복 수를 기록한다. 더 넓은 구간이나 특정 방향을 사전 가정하지 않는다.
2. 운영: 실제 exporter 이름과 라우트에 맞는 Prometheus recording/alert rules, promtool 시험, 런북을 제공한다. 경보의 발화·복구와 부족/오류/미수집 상태를 구분한다. 고객별 운영 임계값으로 검증했다고 주장하지 않는다.
3. 강건성: 기존 동결 PyTorch 3후보 × 3세계 × 2학습 시드를 재사용해 연속·선택적 메모 누락, 문자 치환·축약, 기록 지연을 같은 성숙 미래 대상에서 비교한다. 기존 모델 해시를 확인하고 이 결과로 재학습·선택·운영 전환을 조정하지 않는다. 방법과 조건을 실행 전에 고정한다. 결과가 나쁘면 그대로 보고하고 안전한 메모 미사용 비교군을 유지한다.
4. 접근 제어: 보호 모드에서 로그인·로그아웃, 암호 해시, 만료·취소 가능한 세션, CSRF/Origin 보호, 관리자/고객사 권한을 구현한다. 사이트 목록·직접 URL·업로드·내보내기·세션을 서버에서 제한한다. 데모 모드는 합성 공개용이다. 실제 계정·고객 데이터나 공개 기본 비밀번호를 만들지 않는다. 임시 검증 계정은 로컬에서만 생성·폐기한다.
5. 모델 선택: 기존 번들의 HGB·메모 제외·단순 비교 모델을 고객사별 동일 대상·검증 기간에서 비교하는 실행 가능한 선택기를 만든다. 기록 완전성·표본·시간 경계·정상 입력 오차 기준을 충족할 때만 선택하며 부족하면 기본 모델을 유지한다. 선택 증거와 데이터/번들 해시·기간을 기록하고 원자적 활성화·롤백을 제공한다. 추론·설명·내보내기에 실제 선택 모델을 표시하고 과거 기준일에 미래 선택을 소급하지 않는다. 실제 고객별 최적화라고 주장하지 않는다.
6. 사용성: 7과업의 시작/중단/완료·도움·참가자 의견을 기록하고 JSON으로 내보내는 로컬 기록 도구와 검증기를 제공한다. 조작 시간과 시스템 대기를 자동 혼동하지 않는다. 가짜 참가자 응답이나 측정치는 입력하지 않는다. 실제 재측정은 미완료로 유지한다.

## 대안

신뢰구간을 제거하는 최소 수정도 가능하지만 불확실성을 보여 주기 위해 군집 재표집을 택했다. 인증 SaaS/대규모 MLOps 재작성은 새 비용·의존성과 범위를 늘리므로 기존 서비스의 선택형 보호 모드와 파일 기반 검증 레지스트리로 구현한다. 실서비스 장기 운영 또는 현장 성능을 완료한 것으로 확대하지 않는다.

## 완료 근거

회귀 RED/GREEN, 원시 실험 재계산, 전체 테스트·lint·release 계약, 보호 모드의 서로 다른 사용자/고객사 직접 접근·세션 탈취 거부·로그아웃·만료 검사, 후보 선택/롤백과 실제 예측 일치, 브라우저 데모, CI/Docker/기존 AWS 배포를 확인한다. 사람의 재측정·현장 결과가 없으면 그 항목은 준비 완료/실측 대기로 남긴다.
