# PyTorch 메모 누락 대응 설계

사용자가 PyTorch 누락 대응 보완을 요청했다. 방법·검증 기준은 구현자가 정한다. 기존 합성 안정성 실험과 배포 HGB는 보존한다.

## 선택한 방법

- 기존 text+site: 전체 수치 특징과 문자 CNN. 재학습 대조군.
- missing-aware text+site: 메모 파생 수치 특징을 모두 제외하고 문자 CNN만 텍스트 입력으로 사용한다. 빈/공백 메모의 CNN 출력을 0으로 게이트하고 존재 여부 1채널을 추가한다. 학습 배치에서 행별 확률 0.35로 문자를 모두 가린다. 수치 특징은 메모에 독립적이므로 가려진 원문 정보가 남지 않는다.
- no-memo PyTorch: 같은 메모 독립 수치 특징, use_text=False. 간단한 비교군.

숫자 특징 전체에 임의 dropout을 적용하는 방식은 사용하지 않는다. 원문만 지우고 메모 파생 숫자를 남기는 방식은 학습/추론 불일치가 생기므로 제외한다. 고객별 모델 자동 전환은 이 작업에 포함하지 않는다.

## 고정 평가

이 설계는 새 결과를 보기 전에 커밋한다. 신규 생성 시드 202610251/202610252/202610253, 학습 시드 17/29. 전체 규모 scale=1, 36개월, 시간 순서 24/6/6개월. 기존 실험과 날짜 범위는 같지만 새 합성 세계이며, 현실 시간의 신규 고객 자료는 아니다. 학습 40 epoch, patience=6, lr=.002, batch=1024. 모든 모델의 조기종료는 깨끗한 검증 NLL을 사용한다. 기준 모델의 기존 동작은 유지한다.

학습 종료 이후 원자료 메모에 25/50/100% 누락을 주고 전체 파생 특징을 다시 계산한다. 검증·테스트의 동일 날짜/설비, 사이트별 주간 상위 10개를 비교한다. 100%는 극단 스트레스 보고용으로 선택에 사용하지 않는다. 레이블은 각 시간 경계에서 관측 가능한 것만 사용한다.

각 실행에서 검증 clean/25/50의 주간 Precision@10을 본다. 후보는 clean 하락 <= 1%p, 25/50 평균 향상 >= 2%p, 두 누락 조건 모두 기준 이상, clean Brier <= 기준의 1.05배일 때 적격이다. 적격 후보 중 누락 조건 평균 Precision@10가 높은 것을 선택(동률 no-memo 우선), 아니면 legacy 유지. 선택 JSON을 저장한 뒤 최종 테스트를 평가한다. 후보와 기준은 모두 보고한다.

최종 보완 효과 채택 기준: 검증에서 고정한 선택의 테스트 결과가 6회 모두 clean 하락 <= 2%p, 25/50 평균 향상 >= 0이고, 6회 전체 평균 누락 향상 >= 2%p, clean 평균 하락 <= 1%p, clean 평균 Brier <= 기준 1.05배. 실패해도 결과를 공개하고 재튜닝하지 않는다. 성공해도 실제 고객 일반화나 HGB 대비 우위를 뜻하지 않는다. 주간 결과의 사이트 단위 paired bootstrap 2000회로 반복 설비/겹치는 기간을 유지한다.

## 호환성과 확인

기존 체크포인트는 새 플래그가 없으면 legacy로 불러온다. 옵션 기본값은 legacy 유지. 신규 저장/로드 예측 일치, 공백/None, 전부 누락, 비학습 랜덤 변경 없음, 메모 파생 특징 차단, 입력 원본 불변, 재현성, 빈 입력 shape를 검사한다. 일반 단어를 임의로 결측으로 판단하지 않는다.
