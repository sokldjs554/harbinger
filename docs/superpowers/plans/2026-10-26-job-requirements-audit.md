# 공고 요구 기술·실행 근거 감사 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 첨부 공고의 업무·자격·우대 항목을 실제 코드와 실행 근거에 연결하고 재현한 결함을 수정한다.

**Architecture:** 기존 FastAPI·AWS와 승인된 화면을 유지한다. TensorFlow는 별도 환경의 대조 실험으로 검증하며 서비스 모델을 이유 없이 교체하지 않는다. 모델/평가와 서비스/운영 코드는 독립적으로 검토하고 통합 검증한다.

**Tech Stack:** Python, NumPy/Pandas, scikit-learn/lifelines, PyTorch, TensorFlow/Keras, FastAPI, HTML/JS, Docker, 기존 AWS·Pages.

**Spec:** 2026-10-26 사용자 첨부 공고와 “실제 역량 검증 중심: FastAPI·AWS 유지, TensorFlow 실행 보완” 선택.

## 제약

- 기준 main `27051f07bd7597bd53442c98c281f9240f942e4f`; 기존 브랜치·산출물·검증 기록을 보존한다.
- 실제 고객 성능·학력·근무 경력·사람의 재측정 결과는 만들지 않는다.
- 유료 리소스 신규 생성·공개 서버 부하 시험·비밀값 출력은 하지 않는다.
- 과거 산출물을 수정한 코드의 재학습 결과로 바꾸어 부르지 않는다.

## 검토 중점

- 생존 구간 경계와 프레임워크 간 손실 정의가 같은지 손계산 예제로 검사한다.
- 전부 결측인 특징·한 종류 정답에서 NaN 성능이나 거짓 성공을 만들지 않는다.
- 반복 학습의 무작위 입력 변환은 명시한 확률과 실제 입력이 일치해야 한다.
- 자료 없는 API·보고서는 정상 숫자나 500 응답으로 바뀌지 않아야 한다.
- 문서의 현재 수치와 과거 실행 기록/배포 버전을 구분한다.
