# PyTorch Missing Memo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add an opt-in missing-aware PyTorch model and measure robustness on fresh synthetic worlds.
**Architecture:** Legacy-compatible HazardNet, gated text/presence and training memo dropout; isolated offline selection/evaluation runner.
**Tech Stack:** Existing Python, PyTorch, Pandas, pytest, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-10-25-memo-design.md

## Global Constraints

Existing experiment artifacts and HGB defaults unchanged. Seeds 202610251/252/253 ×17/29; scale1; 36months; 24/6/6 split. 40epochs/patience6; dropout .35. Validation selection freezes before test. Thresholds exactly as spec. No paid external API or new cloud resources.

## Review Focus

- Old checkpoint loads without new metadata and matches prediction.
- Empty/whitespace/None input equivalent only in new mode; Unicode unknown words remain present.
- Text-derived numeric input cannot bypass dropout.
- Validation outcome maturity and decisions precede final test; freeze saved before test scoring.
- Missing worlds keep original outcomes, IDs, nontext predictors, and common decision population.
