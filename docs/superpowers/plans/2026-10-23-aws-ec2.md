# AWS EC2 deployment Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 저장 결과 재생과 별개로 실제 계산이 가능한 AWS HTTPS 데모를 배포한다.

**Architecture:** GitHub Actions에서 이미지와 모델을 준비하고 태그로 제한된 EC2에 임시 SSH로 전달한다. Nginx와 Certbot이 공인 IP HTTPS를 제공하고 systemd가 재시작과 갱신을 관리한다.

**Tech Stack:** Python 표준 라이브러리, AWS CLI, EC2 Instance Connect, Docker Compose, Nginx, Certbot.

**Spec:** docs/superpowers/specs/2026-10-23-aws-ec2-design.md

## Global Constraints
- 계정 577331852023, ap-southeast-2, t3.medium 한 대, gp3 30GiB, IMDSv2 필수.
- Project=harbinger 및 Name=harbinger-demo 소유 리소스만 사용한다.
- 서버에 AWS 자격증명을 복사하지 않으며 임시 SSH 규칙을 finally에서 제거한다.
- FastAPI 공개 포트는 열지 않는다. 업로드 기록은 기존 메모리 세션이며 재시작 보존을 주장하지 않는다.

## Review Focus
- 중복/다른 태그 인스턴스는 변경 없이 거절한다.
- 신뢰할 SSH 공개키가 없으면 접속을 중단한다.
- 전송·설치 실패 시 SSH 규칙을 정리하고 기존 릴리스를 복원한다.
- IP 인증서 갱신은 자동으로 실행되며 웹 서버에 반영한다.
- 첫 배포 실패 시 새 서버를 정지해 컴퓨트 비용의 지속 발생을 줄이고 상태를 기록한다.
