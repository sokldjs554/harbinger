# Remaining gaps implementation plan

**Goal:** 감사에서 남은 통계·운영·강건성·접근제어·모델 선택·사용성 기록의 구현 가능한 부분을 보완한다.
**Architecture:** 기존 API와 모델 번들을 유지하며 독립 모듈로 확장한다. 보호 모드는 선택형, 공개 데모는 합성 자료만 유지한다.
**Tech Stack:** Python, FastAPI, PyTorch, pandas, Prometheus, vanilla JS.
**Spec:** ../specs/2026-10-25-remaining-gaps-design.md

## Global constraints

사람의 평가 결과·현장 자료를 생성하지 않는다. 과거 성능 산출물 보존. 유료 API·신규 인프라 없음. 인증 비밀은 커밋/로그에 기록하지 않음. 소스·자료·모델·선택 출처를 연결한다.

## Review focus

- 인증 사용자 간 세션 ID 전달·다른 고객사 직접 URL·혼합 CSV 우회 거부.
- 과거 기준일에 미래 검증 결과를 소급 적용하지 않음.
- 모델을 바꾸면 근거 설명과 다운로드도 같은 모델을 반영.
- 군집 수 부족/고장 단일 클래스/누락·지연에서 비교 분모 유지.
- 사람 기록 도구는 미실시·도움·재시도·시스템 대기를 구별.
