## Confirmed and repaired defects

1. **P2 — Empty-history Markdown report crashed rather than preserving unknown risk.** `src/harbinger/api/routers/report.py:103`. A legitimate site/date with no recent inspections has `mean_p30=None` and a patrol object without `k` or expectation fields. Formatting raised `TypeError: unsupported format string passed to NoneType.__format__`, followed by missing patrol fields if only the first issue were repaired. Report now explicitly says calculation unavailable and avoids invented zero risk. Dedicated regression invokes the real renderer with this documented empty response shape.
2. **P2 — What-if checklist values bypassed the 0/1/2 domain.** `src/harbinger/api/routers/risk.py:76`. `ScenarioIn(items={"noise": -1/3/128})` accepted all three although upload and inspection schemas constrain this domain. Invalid values could enter feature generation or fail Int8 conversion. Uses the existing CheckResult enum; parameterized tests now reject all three at request validation.
3. **P2 — Short CSV uploads opened before their first inspection.** `src/harbinger/api/routers/workbench.py:61`. An inspection on 2025-08-01 with observation end 2025-08-02 defaulted to 2025-06-18, producing an empty initial analysis even though a record exists. Default date now remains the preferred mature date when available, clamped to the earliest inspection for shorter histories. Follow-up completeness withholding is unchanged.
4. **P2 — Explicitly enabled ingestion left replay caches stale.** `src/harbinger/api/store.py`, ingest_inspections after feature replacement. Replaying the same query before and after ingestion invoked replay_site only once, reusing old recommendations/outcomes. Ingestion now invalidates the replay cache after rebuilding features. Test uses actual Store ingestion/cache orchestration with deterministic feature/replay dependencies, and verifies a second calculation.
5. **P2 — Same-commit deployment overwrote its rollback target and mutable image tag.** `deploy/aws/ec2/install.sh:15,51`. A workflow rerun used the same `$root/releases/$SHA` as both new release and previous target while retraining/extracting a bundle into it. Rebuilt image loading also replaced the commit tag. Each attempt now gets a unique release directory; before image loading it saves the previous container's immutable image ID. Rollback restores that ID to the original commit tag before compose, keeping subsequent systemd restarts consistent. Regression executes the actual installer prefix with harmless host-tool stubs under a temporary directory, checks distinct release paths and image snapshot, then executes rollback with a Docker command recorder and verifies tag restoration. No real Docker or AWS operation is involved in this regression.
6. **P2 — Unsupported date inputs escaped parsing and failed later in pandas.** `src/harbinger/api/store.py:130` and `src/harbinger/api/routers/replay.py:13`. Timezone-aware timestamps were accepted against timezone-naive tables; replay additionally accepted NaT. Validation now explicitly rejects missing or timezone-aware dates with HTTP 422 and a site-local timezone-naive date explanation. Existing timezone-naive/date behavior remains supported. Six parser cases cover both entry points and NaT/Z/+09:00 inputs. Existing as_of NaT already yielded 422 indirectly; it now receives the same explicit rule.
