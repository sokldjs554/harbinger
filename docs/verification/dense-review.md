# 설비 목록과 점검 상세 화면 검토

**이 문서는 최초 두 화면 검토 당시의 기록이다. 이후 사용자 승인으로 전체 기능에 적용했으며 최신 상태는 [전체 검증 기록](README.md)을 따른다.**

2026-10-22 KST. 브랜치 `codex/dwi-dense-list-review`. 공개 배포 전 사용자 확인 단계.

## 범위

`/console/review.html`에 목록과 상세 두 화면을 새로 구현했다. 기존 `index.html`, `workbench.js`, `workbench.css`, `docs/demo`와 백엔드는 변경하지 않았다. 새 화면에서 기존 전체 기능 화면으로 이동할 수 있다. CSV 업로드, 과거 검증, 고객사별 평가, 다운로드의 새 디자인 적용과 공개 배포는 사용자 화면 확인 후 진행한다.

- 흰 작업 바탕, 진한 회색 본문, 얇은 구분선, 파란 주요 동작.
- 고정 사이드바, 상시 우측 패널, KPI 카드 줄, 큰 소개 제목, 베이지 배경 없음.
- 50px 행 높이의 전체 폭 목록, 50개씩 페이지 표시. 전체 2,312개 합성 설비에 검색·고객사·종류 필터·정렬 적용.
- 별도 상세 주소로 이동. 필터·정렬·페이지는 URL, 스크롤·초점은 History API 상태로 복원.
- 점검일별 원문·점검자·종합 판정·지적 항목 표시. 모델 기여 항목에서 관련 원문 또는 정비 기록으로 이동.
- 최신 점검에서 계산한 항목과 여러 기록 집계를 구분한다. 최근 3회만 표시된다는 한계를 명시하며 문장별 인과 설명을 만들지 않는다.
- 새로고침 시 같은 탭의 합성 예제 세션을 재사용한다. 만료·서버 재시작에 따른 404는 한 번 새 세션을 만들어 복구한다. 업로드 기록은 저장하지 않는다.

## 실행과 검증

기존 README의 데이터·모델 준비 후 실행한다.

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uvicorn harbinger.api.main:app --host 127.0.0.1 --port 8765
# http://127.0.0.1:8765/console/review.html
python scripts/check_dense_review.py --url http://127.0.0.1:8765/console/review.html
```

Playwright와 Chromium이 설치된 환경이 필요하다. 이 작업 환경에서는 `.venv/bin/python`과 `PLAYWRIGHT_BROWSERS_PATH=/workspace/harbinger-runs/browsers`를 사용했다.

1. 기존 데스크톱 화면에서 설비 선택 후에도 목록이 표시되는 것을 재현하고, 별도 상세 화면이어야 한다는 assertion 실패를 확인했다.
2. 새 Chromium 검증에서 실제 Python 분석과 설명 API를 호출했다. 화면 원문과 API의 최신 원문이 같은지 확인했다.
3. 검색·고객사·종류 필터의 실제 결과, 날짜 정렬, 목록 페이지 복원, 상세 이동, 뒤로/앞으로 이동, 스크롤·초점 복원, 점검일 변경, 선택한 점검일의 새로고침 복원, 빈 결과, 오류 후 재시도를 통과했다.
4. 1440×1000 데스크톱과 390×844 모바일에서 조작했다. 가로 넘침과 브라우저 pageerror 없음.
5. 반복 새로고침이 새 세션을 만드는 실패를 재현했다(예상 생성 1회, 실제 2회). 수정 후 새로고침 재사용과 서버 세션 삭제 후 복구를 검증했다. 테스트는 자신이 생성한 세션만 종료한다.
6. 전체 Python 테스트: **70 passed, 1 skipped, 43.19s**. 기본 제한 환경에서 멈춘 첫 실행은 중단했고 네트워크 허용 환경에서 재실행해 완료했다. 건너뛴 테스트는 선택 의존성의 Keras parity 테스트다.
7. JavaScript 구문, Ruff, 공백 오류 검사를 통과했다.
