# 동결 모델 확장 스트레스: 방법과 재현

새 [사전 고정 설계](../../superpowers/specs/2026-10-25-extended-stress-design.md)를 결과 생성 전에 커밋했다(`43a4ce5`). 이전 메모 실험의 3개 합성 세계×학습시드2회×모델3개를 재사용한다. 새 학습·재보정·후보 선택은 하지 않는다. 실행 직전에 원자료 parquet 해시와 18개 모델의 저장 구성 파일 해시를 기존 커밋된 provenance/학습 이력과 대조한다. 6회는 독립 세계6개가 아니다. 기존 정상/독립 누락 결과는 이미 알려진 상태에서 확장 조건을 고정했으므로, 새 데이터에서의 독립 확인 실험으로 해석하지 않는다.

이전 실험은 검사마다 독립적으로 메모를 삭제했다. 이번에는 설비 또는 점검자별 연속28일 누락, 메모에 이미 적힌 심각도에 따른 선택적 누락, 한글 모음 문자 치환, 명시적으로 만든 축약어, 점검 기록7일 전달 지연을 각각 시험한다. 모든 조건은 독립 실행하며 복합 장애는 이번 범위가 아니다. 축약어는 예를 들어 `베어링→BRG`, `교체 필요→교체要`, `필터→FLT`이며 현장 어휘를 수집했다고 주장하지 않는다. 문자 치환도 실측 오타 분포가 아니다. 특정 문제 기록이 많이 빠지는 상황은 무작위 삭제보다 더 나쁠 수 있다. 선택적 누락의 실제 전체 비율은 메모 심각도 구성에 따라 달라지므로 다른 조건과 누락률을 맞춘 인과 비교가 아니다.

변환은 원래 학습 종료 이후의 raw memo에만 적용한다. 미래 정답·잠재 상태·고장 이력으로 누락 대상을 정하지 않는다. 원문부터 모든 메모 종속 특징(점검자 품질과 가중 체크리스트 포함)을 다시 계산한다. 원자료가 같은 에너지 특징만 기존 행 ID로 재사용한다. 메모 비종속 입력과 학습 이전 특징·정답은 불변인지 비교한다. 지연은 `decision_snapshot`의 기존 계약대로 최신 도착 점검을 선택하고 의사결정 시점에 시간 의존 특징을 갱신한다. 작업지시서는 즉시 알려진 것으로 두므로 전체 데이터 전달 지연을 검증한 것은 아니다.

기존 테스트의 월요일·사이트·설비·30일 정답을 그대로 사용한다. 조건별로 누락 행을 교집합 처리하지 않고 원래 대상과 정확히 일치하지 않으면 실패한다. 원시 확률·cohort·각 조건의 근거 점검 ID/시간·변환량과 원문 변환 해시를 남긴다. clean 예측은 이전 공개 배열과 비트 단위로 대조하고, 메모 미사용 모델은 모든 메모 손상 조건에서 clean과 비트 단위로 같아야 한다. 실제 기록 지연은 입력이 바뀌므로 이 불변성 요구에서 제외한다.

AUROC, PR-AUC, Brier, logloss와 사이트별 주간 Precision@10을 저장한다. 같은 원시 배열에서 표본 수·사이트·예산·지표·2000회 paired site bootstrap을 다시 계산한다. 각 모델의 손상−정상, 각 후보의 기존 모델 대비 차이에 대한 구간을 저장한다. 사이트별 모든 반복 설비/주간 행을 한꺼번에 재표집한 구간은 해당 합성 세계에 조건부이며 실제 고객 전체의 신뢰구간이 아니다.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONPATH=src:.
# work에는 이전 memo_robustness 실험으로 생성한 원자료와 동결 모델이 필요하다.
for seed in 202610251 202610252 202610253; do
  python -m scripts.extended_stress.run --data-seed "$seed" \
    --work /tmp/hb-memo-full --out /tmp/extended-stress-results
done
python -m scripts.extended_stress.summary /tmp/extended-stress-results
# 저장된 공개 결과의 원시 재계산 (모델/원자료 다운로드 불필요):
python -m scripts.extended_stress.summary docs/verification/remaining-gaps-20261025/stress-results
```

출력 경로는 기존 결과가 있으면 거부한다. 한 번에 세계 하나만 실행한다. 결과의 양/음과 무관하게 기존 선택/채택 기준이나 배포 모델을 바꾸지 않는다. 이 검사는 고정된 합성 조건에 대한 민감도 근거이며 고객 성능이나 현장 운영 적합성을 증명하지 않는다.
