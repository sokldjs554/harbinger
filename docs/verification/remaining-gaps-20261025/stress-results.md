# 확장 스트레스 결과: 동결 모델 6회 재검증

18개 기존 PyTorch 모델을 재학습 없이 평가했다. 3개 합성 세계×학습 시드2회이며, 각 실행에서 같은 25개 사이트·22개 월요일·사이트당 상위10개(총 5,500회 선택)를 사용했다. 평가 날짜는 2025-07-07부터 2025-12-01까지다. 세계별 대상 행은 48,532 / 47,564 / 50,028개이며 조건 때문에 제외된 대상은 없다.

| 조건 | 기존 모델 | 개선형 | 메모 미사용 |

기존 모델은 설비별/점검자별 연속 누락에서 정상 대비 평균 6.25/6.17%p 낮아졌다. 개선형의 같은 감소는 0.24/0.21%p였지만 정상 성능은 기존보다 평균 0.50%p 낮았다. 개선형이 모든 실행·지표에서 우월하다는 뜻은 아니다. 메모 미사용의 모든 메모 손상 확률은 정상 확률과 **비트 단위로 동일**하다. 실제 기록 지연에서는 이 모델도 평균 0.81%p 감소했다.

이전 독립 무작위50% 삭제에서 기존 모델 평균은17.71%였다. 이번 설비/점검자 연속 누락의17.45/17.53%는 그보다 낮다. 누락 패턴이 바뀌어도 이전 삭제 실험 결과가 그대로 적용된다고 볼 수 없다. 선택적 누락은 전체 약26%를 삭제했지만 심각한 문구에 집중한다. 다른 조건과 정확히 비율을 맞춘 인과 비교는 아니며, 관측하지 않은 분포에서는 더 나쁠 수 있다.
