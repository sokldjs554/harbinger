## 반복 기록과 경보 조건을 바로잡았습니다

[신호표·경보 상세](signals-ops.md), [전체 신호표](signals-ops-full.json), [전후 비교](signals-ops-comparison.json). 같은 점추정을 유지하고 내부 반복 기록을 고객사 단위로 묶었습니다. 15개 셀 중 한 구간은 더 좁아졌습니다. 항상 넓어진다고 주장하지 않습니다. 기존 역사적 `artifacts/signals.json`은 보존하고 화면에 구식 Wilson 방식임을 표시합니다.

공식 Prometheus 2.54.1의 해시를 검증한 도구로 규칙·12개 테스트 그룹·설정 검사에 성공했습니다. [CI와 같은 명령의 출력](monitoring-ci.txt). 현재 AWS에 장기간 수집 중인 경보 체계나 수신자 알림까지 구축했다고 주장하지 않습니다.

## 다른 고객의 자료와 선택 근거를 섞지 않았습니다

[보호 모드 실행](../../protected-mode.md) · [독립 접근 제어 검토](security-review.md) · [통합 소스의 163개 우회 검사](security-final.txt). 두 독립 브라우저 계정에서 고객사 선택·다운로드·직접 URL 거부·분석 토큰 소유권·로그아웃 취소를 확인했습니다. 계정은 검사 때만 생성하고 제거했으며 공개 데모용 영구 계정이나 암호를 만들지 않았습니다.

[고객사 모델 정책 안내](../../site-model-policy.md) · [실제 합성 추론·선택·롤백 증거](../remaining-gaps/site-policy/README.md). 4개 합성 사이트 중 1곳에서 메모 제거 모델이 선택됐고 나머지는 기본 모델을 유지했습니다. 예약한 미래 테스트는 아직 수행하지 않았습니다. 선택된 모델의 SHAP을 지원하지 않으면 기본 모델의 설명을 대신 붙이지 않습니다.

[최종 독립 코드 검토](final-review.md)에서 지적한 두 주요 오류는 수정 후 재검증을 통과했습니다. 통합 검토에서 혼합 고객사의 평가 보류 조건이 순회 순서에 따라 달라지는 오류, 기존 보고서에 선택 모델이 빠지는 오류를 재현하고 수정했습니다. [실패→수정 검사](../remaining-gaps/site-policy/review-followup/README.md). 브라우저 CSV의 별도 열 목록에서도 모델 정보가 빠져 [실패를 재현](browser-trace-red.txt)한 뒤 CSV·Markdown·상세 화면까지 연결했습니다.

## 사람의 결과를 대신 쓰지 않는 기록 도구를 만들었습니다

[기록 화면](https://sokldjs554.github.io/harbinger/retest.html) · [진행·비교 안내](../../user-reviews/retest-guide.md). 결과는 사용자의 브라우저에서 JSON으로 내려받습니다. 도구에는 원격 전송·자동 저장이 없습니다. 수행·수동 대기·중단을 분리하지만 시스템 대기 시간을 서버에서 자동 계측한 것은 아닙니다. 입력 검증은 실제 참여 사실을 증명하지 않습니다.

[실제 브라우저 도구 검사](retest-tool-checks.json)는 `tool-test` 자료입니다. [독립 검토](core-review.md)에서 발견한 도움 내용 누락·음수 시간 허용도 실패를 재현한 뒤 수정했습니다. 기존 두 참가자 의견과 추가 문제가 없다는 회신은 그대로 보존하며, 시간 단축·무도움 성공률을 새로 주장하지 않습니다.
