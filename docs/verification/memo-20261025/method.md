# 누락 대응을 어떻게 비교했는지

## 이전 결과를 보존하고 새 자료를 만들었습니다

이전 안정성 실험의 생성 시드20260101/2/3과 결과는 수정하지 않았다. 새 시드202610251/252/253 × 학습 시드17/29를 사용했다. 3개 합성 세계 안에 학습2회가 중첩돼 있으며 독립적인 실제 고객6곳이 아니다. 생성기와 달력 기간은 이전과 같고, 생성 가정 밖의 실제 현장 일반화를 입증하지 않는다.

scale=1, 36개월, 시간 순서24개월 학습·6개월 검증·6개월 테스트다. 학습/검증 구간 말미에서 30일이 지나지 않은 분류 정답을 제외하고 생존 관측을 중도절단한다. 매주 월요일, 사이트별 상위10개를 같은 대상과 예산으로 비교하며, 각 단계의 종료 전에 이후30일을 관측할 수 있는 날짜만 사용한다.

## 세 모델을 같은 조건에서 학습했습니다

| 비교군 | 원문 메모 | 메모 파생 수치 | 누락 학습 |
|---|---|---|---|
| 기존 PyTorch text+site | 문자 CNN | 포함 | 기존 방식 유지 |
| 개선형 PyTorch | 문자 CNN + 존재 여부; 빈 입력 CNN 출력을0으로 차단 | 제외 | 행별 확률0.35로 학습 배치의 문자 입력을 가림 |
| 메모 미사용 PyTorch | 미사용 | 제외 | 필요 없음 |

세 모델 모두 최대40epoch, patience6, batch1024, lr0.002, 동일 학습 시드를 사용한다. 조기종료는 깨끗한 검증 자료의 생존 NLL로 결정한다. 메모 dropout은 별도의 재현 가능한 난수 생성기를 사용하며, 추론에는 적용하지 않는다. 기본 모델 구조나 입력 차원까지 동일한 절제 실험은 아니므로, 차이 전체를 dropout 하나의 인과 효과로 설명하지 않는다.

개선형과 메모 미사용 모델은 tx 특징뿐 아니라 메모에 의존하는 점검자 품질·가중 판정 특징도 제외한다. 제외 목록은 기존 `model_columns(..., groups without tx)` 계약을 따른다. 개선형 학습에 이 특징이 남아 있으면 오류로 거부한다. 빈 문자열·None·공백만 누락으로 처리하고, 알 수 없는 글자는 존재하는 메모로 유지한다.

## 원자료부터 가리고 다시 계산했습니다

학습 구간 이후의 점검 메모를25/50/100% 확률로 빈 문자열로 바꾸고 모든 파생 특징을 다시 만들었다. 검사별 결정적 난수로 누락을 정하며 정답은 바꾸지 않는다. 학습 이전 특징·정답 불변, 메모 독립 수치 특징 불변, 평가 조건 사이의 사이트·설비·날짜·정답 일치를 실행 중 확인한다. 메모 미사용 모델의 네 조건 예측이 완전히 같은지도 원시 배열로 검사한다.

누락은 독립적인 무작위 삭제다. 실제로 중요한 기록만 빠지는 상황, 특정 담당자·설비의 연속 누락, 현장 은어의 분포 변화까지 검증한 것은 아니다. 100% 누락은 극단 스트레스로 보고하며 후보 선택에는 사용하지 않았다.

## 선택은 검증 구간에서 끝냈습니다

[사전 설계](../../superpowers/specs/2026-10-25-memo-design.md)의 기준을 결과 확인 전에 커밋했다. 검증 구간에서 후보가 다음 조건을 모두 만족해야 선택 대상이 된다.

- 정상 입력의 주간 Precision@10 하락이1%p 이하.
- 누락25/50% 평균 향상이2%p 이상이고, 두 조건 모두 기존 모델 이상.
- 정상 입력 Brier가 기존의1.05배 이하.

적격 후보 중 누락 조건 평균 Precision@10이 높은 것을 선택하며, 동률이면 메모 미사용을 우선한다. 적격 후보가 없으면 기존 모델을 유지한다. 선택 파일과 검증 결과 해시를 저장한 후 테스트를 계산한다. 테스트 결과를 본 뒤 선택이나 설정을 바꾸지 않는다.

최종 채택 판정도 사전에 고정했다: 6회 모두 정상 입력 하락2%p 이하·누락 평균 향상0 이상, 6회 평균 누락 향상2%p 이상·정상 입력 하락1%p 이하·정상 Brier 기존1.05배 이하. 이는 구현자가 정한 합성 실험 판정 기준이며 고객의 비용이나 안전 기준에서 도출한 운영 임계값이 아니다.

사이트 단위 paired bootstrap2000회는 각 합성 세계의 반복 설비·겹치는 주간 결과를 함께 재표집한다. 각 실행에 조건부인 구간이며 전체 세계나 실제 고객의 신뢰구간으로 확대하지 않는다.

## 결과를 재현하려면

[개발 환경](../../running.md)을 설치하고 저장소 루트에서 실행한다. 유료 API는 사용하지 않는다. 출력 경로가 이미 있으면 덮어쓰지 않고 중단한다.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
for seed in 202610251 202610252 202610253; do
  python -m scripts.memo_robustness --data-seed "$seed" --work /tmp/memo-reproduce --out /tmp/memo-results
done
python -m scripts.memo_summary /tmp/memo-results
```

동작 확인만 필요하면 별도 빈 경로에서 `--smoke`를 사용한다. smoke는 scale0.08, 학습2epoch, 학습 시드17, 단계별 월요일2개이므로 본 실험 성능으로 사용하지 않는다. 저장한 공개 결과는 `python -m scripts.memo_summary docs/verification/memo-20261025/results`로 지표·선택·해시·시간 경계·메모 미사용 예측 불변·bootstrap을 다시 검사할 수 있다.

원자료와 모델 가중치는 재현 작업 디렉터리에 생성한다. 저장소에는 메모 변환 자료, 평가 대상/정답, 원시 예측, 학습 이력, 데이터·코드·모델 해시, 패키지 버전과 결과를 보존한다. 공개 서비스의 HGB나 기본 PyTorch 체크포인트를 이 실험으로 자동 교체하지 않는다.
