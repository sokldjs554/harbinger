# 모바일 필터와 문구 정리 — 2026-10-22 KST

기존 설비 목록 디자인을 유지하고 세 부분만 수정했다.

- 650px 이하에서 검색창은 유지하고 고객사·설비 종류·정렬·예측 기준일을 상세 필터로 접는다. 요약은 실제 적용 조건을 표시하며 조회 전 날짜 변경은 별도로 표시한다. 펼침 상태도 주소에 보관하여 상세에서 복귀할 때 복원한다.
- 판단 방향은 ‘위험 추정을 높인 항목·위험 추정을 낮춘 항목’으로 표시한다. 모바일에서는 항목명 아래 한 줄을 확보한다.
- 실행 방식은 모바일 제목 아래 전체 폭으로 표시한다. 실제 API는 ‘합성 예제 · Python 계산 완료’, 공개 데모는 ‘합성 예제 · 저장 결과 재생’이다.

`check_mobile_filters.py`를 기존 전체 브라우저 검사에 연결했다. 실제 API와 저장 데모 모두 검색 유지, 네 가지 조건, 날짜 적용 전/후, 접은 상태의 조건 요약, 상세 왕복과 뒤로/앞으로 이동, 초점·스크롤·펼침 상태 복원, 320/390/650px의 문구 및 가로 넘침을 검사한다. PR CI에서도 저장 데모를 확인한 후 병합한다. Pages 배포는 같은 검사를 다시 수행하고 실제 모바일 캡처를 `mobile-captures/`에 공개한다.

로컬 서버 실행 권한 요청이 완료되지 않아 브라우저 실행은 GitHub CI에서 수행한다. 로컬 JavaScript 구문·Ruff·포맷·문서 수치·릴리스 해시 검사를 통과했다. 모델, 데이터, 평가 수치는 변경하지 않았다. 실제 브라우저 및 공개 배포 결과는 이 변경의 PR과 검토 페이지에 기록한다.
