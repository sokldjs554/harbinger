# Independent review follow-up

Two integration seams were reproduced and fixed after initial implementation commit `3c1d794e51997c918fb7f603ee32e78d0dba3260`. Initial evidence in the parent directory remains a record of that commit; this follow-up records the changed replay/report behavior.

1. Pooled replay eligibility previously inherited only the first site's flag. The regression uses the actual `replay_site` and `replay` functions: S1 is eligible after the base model cutoff, S2 has a later reserved policy test start. Both site orders now produce an ineligible pooled week, preserve all 10 raw assets in the denominator, and withhold certified summary metrics. A later date makes both sites eligible and restores the available summary.
2. Legacy reports previously omitted selected-model provenance and exposed the bundled baseline headline alongside selected-model scores. Report JSON and Markdown now identify selected model, policy revision, reason and reserved test start. Top assets retain their actual score trace. A nonbaseline route has `model.headline=null` with `withheld_for_selected_model`; the stored metrics remain explicitly named `baseline_reference`. Baseline reports preserve the existing headline object and add the `stored_bundle_baseline_reference` scope.

`red.txt` records 3 failing cases and 1 passing reverse-order case before fixes. `focused-green.txt` records all 4 cases passing after fixes. `full-pytest.txt` records **188 passed, 1 optional TensorFlow skip in 43.99 seconds** with `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONPATH=src:. python -m pytest -rs`. Ruff and `git diff --check` also pass.

`runtime-report.json` additionally checks the actual S01 `without_text` route in the existing synthetic runtime. To place records after activation without changing files, datetime columns and feature `t` values were shifted three years **in memory only**, and the observation boundary shifted equally; the report used 2026-12-15. All 104 scored assets matched the selected classifier directly; JSON/Markdown and top-asset traces matched the active policy; the baseline headline was withheld and its stored reference labelled. This is an operational routing/report check, not performance evidence. No shared runtime files, production settings, authentication boundaries, or browser report code were changed.
