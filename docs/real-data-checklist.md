# 실데이터 적용 체크리스트 — 실증(PoC) 첫 4주

아래는 **미실시 실데이터 실증(PoC)의 계획안**이다. 고객사 한 곳(초기 검토 조건의 예: 정부청사형, 설비 80개 이상, 점검 기록 24개월 이상)으로 시작하되, 표본·고장 건수·업무 여건에 따라 실증 가능 여부를 먼저 판단한다. 친구·동료의 화면 사용성 검토는 [별도 절차](user-review.md)로 진행하며 고객 실증 실적으로 합산하지 않는다.

## 1주차 — 데이터 적합성 (모델 없이)

- [ ] 테이블 매핑: FMS 의 설비 분류 → 12종 카테고리 매핑표 작성. 매핑 안 되는 설비 비율 기록.
- [ ] **비계획 고장의 정의 합의.** 고장수리 WO 중 "점검 중 발견 → 계획 조치"를 분리할 수 있는가? 안 되면 라벨 노이즈로 기록.
- [ ] **평가 전에 운영 결과와 관측 창을 확정한다.** 어떤 사건을 적중으로 셀지, 예측 기준일·향후 관측 기간(현재 구현은 30일)·관측 종료일·기록 완전성·제외 조건·점검 예산 k를 문서에 남긴다. 모델 결과를 본 뒤 유리한 창을 선택하지 않는다.
- [ ] **실제 비교 정책을 현장 담당자와 합의한다.** 현재 순찰 대상 선정 방식, 법정·필수 점검, 동점 처리, 긴급 조치와 가용 인원을 확인하고 같은 대상·날짜·예산으로 비교할 수 있는지 기록한다. 실제 정책을 재현할 자료가 없으면 현장 정책 대비 효과는 미검증으로 둔다.
- [ ] 점검 기록의 `performed_at` 이 실제 수행 시각인지(비콘/NFC 로그) 아니면 입력 시각인지 확인. 체류 시간 유무 확인.
- [ ] 메모 통계: 길이 분포, 빈 메모 비율, 상위 20개 상투어, 약신호 수식어("약간", "미세", "간헐") 출현율. **메모가 체크리스트보다 먼저 움직이는지**를 다음으로 확인:
      고장 전 60일 안의 점검 중 체크리스트가 양호인데 메모에 증상 어근이 있는 비율 vs 고장 없는 설비의 같은 비율.
- [ ] 에너지: 검침 주기(일/월), 기온 데이터 확보(기상청 ASOS 지점), 재실 proxy(출입 기록·근무 관리 메뉴).

## 2주차 — 베이스라인과 상한

- [ ] `harbinger features` 로 피처 빌드, `label_valid` 행 수·양성률·실제 고장 건수·고객사별 분포를 확인한다. 희소하면 추가 관측 또는 평가 보류를 검토한다. 양성률을 높이려고 자동으로 관측 창을 늘리지 않는다. 업무상 다른 창이 필요하면 별도 평가 계획과 구현·검증 후 비교한다.
- [ ] 연식 · 최근 점검 판정 · 라운드로빈의 AUROC/precision@k를 가능한 범위에서 보고한다. 이는 **프로젝트가 정한 비교 규칙**이며 실제 현장의 정책이라는 근거는 없다. 1주차에 합의한 실제 정책을 별도 비교군으로 두고 재현 가능 여부를 표시한다.
- [ ] 시간 분할로 HGB 학습. 절제 실험(체크리스트만 → +메모 → +품질 → +이력 → +에너지)으로 **고객사 데이터에서 무엇이 실제로 기여하는지** 확인.

## 3주차 — 처방과 현장 검증

- [ ] 지난 6개월의 매주 월요일에 대해 `patrol/today?as_of=` 를 재현하고, 사전에 정한 30일 관측 창이 완료된 날짜만 실제 고장과 대조한다(precision@k, 합의한 실제 정책 및 프로젝트 비교 규칙 대비 lift). 같은 설비의 반복 선택과 겹치는 창을 고려해 불확실성도 보고한다.
- [ ] 현장 반장 2명과 상위 10개 목록을 함께 보며 "말이 되는 근거인가"를 묻는다. 근거 문장이 틀리게 읽히는 피처는 뺀다.
- [ ] 점검자 품질 리포트는 **개인 평가가 아니라 기록 체계 개선 자료**로만 쓴다고 고객과 합의한다(점검자 ID 가명화).

## 4주차 — 운영 형태

- [ ] 번들 레지스트리 + 월간 재학습 + 드리프트 경보 설정.
- [ ] API 를 FMS 의 "오늘 할 일" 화면에 연결(상위 k + 근거 2줄).
- [ ] 리포트(`/report?format=md`)를 고객 월간 보고서 양식에 맞춘다.

## 성공 기준 (제안)

다음 숫자는 **아직 달성하지 않은 초기 제안값**이며 업무 비용·기존 성능·표본 수에 근거해 확정한 기준이 아니다. 고객과 평가 전에 타당성을 검토하고 확정값과 이유를 기록한다. 합성 실험이나 지인 피드백으로 달성을 주장하지 않는다.

- 상위 10개 목록의 30일 적중률이 라운드로빈 대비 **2배 이상**, 캘리브레이션 ECE **0.03 미만**이라는 제안. 실제 정책 대비 결과도 함께 보고하며, 비교군 적중률이 0이거나 사건이 부족하면 배수로 성공을 판정하지 않는다.
- 현장 반장이 상위 10개 중 **7개 이상에 "볼 만하다"**고 답한다는 제안. 선택 근거·반대 의견을 함께 기록하고, 주관적 관련성 평가와 이후 실제 고장 적중을 분리한다.
- 법정 점검 누락 0건이라는 제안. 필수 점검 목록과 실행 로그를 대조해 검증할 항목이며 현재 달성·보장한 결과가 아니다.
